I build web applications and storefronts that connect clean interfaces with practical business workflows. My work spans **React, TypeScript, Node.js, Supabase, PostgreSQL and Shopify Liquid**, from CRM dashboards and event platforms to custom e-commerce experiences.

<p align="center"><img src="./assets/portfolio-services.svg" width="100%" alt="Full-stack applications, Shopify storefronts and automation workflows" /></p>

### What I build

- **Full-stack applications:** SaaS platforms, CRM systems, dashboards, REST APIs and third-party integrations.
- **Shopify storefronts:** OS 2.0 theme customization, reusable Liquid sections, product layouts and storefront refinements.
- **Business websites:** WordPress, WooCommerce, Webflow and Framer websites built around clear content and responsive layouts.
- **Automation & AI projects:** Connected workflows, voice agent integrations and computer vision projects.
